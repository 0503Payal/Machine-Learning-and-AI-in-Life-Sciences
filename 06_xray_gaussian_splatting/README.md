# X-Gaussian Splatting — literature review

Group project with **Ksenia Krasikova**, **Payal Priyadarshini** and **Philipp Harlos** (equal contribution).
Part of the lab seminar *Machine Learning and AI in the Life Sciences: Methods and
Applications*, Freie Universität Berlin.

## Goal

Review the Radiative Gaussian Splatting paper (Cai et al., 2024) and a related
paper, both of which extend 3D Gaussian Splatting to specific reconstruction
problems in X-ray imaging.

## Result

A written review of two papers building on 3DGS technology. This project is a
review, so it has no accompanying code.
