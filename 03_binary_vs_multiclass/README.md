# Comparative Prediction Analysis of Binary and Multiclass Classification

Group project with **Ksenia Krasikova**, **Payal Priyadarshini** and **Philipp Harlos** (equal contribution).
Part of the lab seminar *Machine Learning and AI in the Life Sciences: Methods and
Applications*, Freie Universität Berlin.

## Goal

Build binary and multiclass classifiers on transcriptomics data and benchmark
them against an existing SVM baseline, on both metrics and the features they
select.

## Result

The binary models reach high performance; the multiclass models are
substantially weaker, which the report analyses.
